#+title: Shape Artist
#+subtitle: Rapid ASCII Diagram Prototyping for Emacs

* Overview

Shape Artist is an Emacs package for creating ASCII diagrams quickly.
It provides vim-style navigation with automatic shape detection,
making it easy to draw boxes, lines, and labels in plain text.

** Highlights

- Draw with =h/j/k/l= keys, like Vim
- Automatic rectangle and edge detection
- Shape selection and editing (labels, move, resize)
- Straight connector attachment and sticking during moves
- Normalization: trim, pad, and box with title
- Evil integration with custom states
- Sidebar UI with live shape information

* Installation

** Requirements

- Emacs 27.1+
- Evil (optional, for Vim-style states)

** From source

#+begin_example
git clone https://github.com/example/shape-artist.git
cd shape-artist
eldev test
#+end_example

Add to your init file:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/shape-artist")
(require 'shape-artist)
#+end_src

* Usage

=M-x shape-artist-scratch= opens a new artist buffer with the
sidebar.  From there:

1. =d= enters DRAW mode
2. =h/j/k/l= draws lines
3. =SPC= sets an anchor, then move to define a rectangle
4. =RET= commits the shape
5. =C-n= enters SELECT mode to pick a shape
6. =RET= in SELECT locks the shape for editing
7. In SELECT, use =t= to mark multiple shapes or =T= to select all.
8. In SHAPE-EDIT, use =H/J/K/L= to move the locked shape or group, =>= / =<= to change width or edge length, =+= / =_= to change height or vertical edge length, =[= / =]= and ={= / =}= for left/top anchored resize, and =x= to cycle border or arrow style.
9. Press =?= for the mode-aware quick action menu, =o= for the outline tree,
   or =z= to center the parsed diagram.

See the [[file:doc/shape-artist.org][full manual]] for complete documentation.
