* Introduction

Shape Artist is an Emacs package for rapid ASCII diagram prototyping.
It provides auto-discovered shape detection, fuzzy selection, and
shape manipulation, layered on top of =picture-mode=.

Shape Artist integrates with Evil (Vim emulation) when available,
providing custom states for drawing, selection, and shape editing.
It works without Evil as well, using standard Emacs keybindings.

** Features

- *DRAW mode*: Move with =h= / =j= / =k= / =l=, drawing lines and
  rectangles as you go.
- *Shape detection*: Detects coherent ASCII/Unicode rectangle families, edges,
  orthogonal connector bends, and labels while rejecting malformed mixed-border
  boxes rather than guessing.
- *Graph analysis*: Groups orthogonal edge segments into logical connectors and
  derives rectangle adjacency, connected components, and shortest paths.
- *Stable shape IDs*: Parsed rectangles, connectors, and labels get
  buffer-local IDs that remain stable across unchanged reparses.
- *SELECT mode*: Cycle through detected shapes with =n= / =p= and
  lock in for editing.
- *SHAPE-EDIT mode*: Edit labels, move, or resize locked-in shapes.
- *Normalization*: Trim blank rows/columns, add padding, and
  optionally box with a title.
- *Sidebar UI*: Persistent sidebar showing state, shapes, labels, graph health,
  guides, and context-sensitive keybindings.
- *Strong modal feedback*: Theme-aware header/mode/sidebar badges, distinct
  cursor forms, SELECT candidate/selection overlays, and SHAPE-EDIT target
  highlighting all follow one central transition contract.
- *Outline buffer*: Tree view of the detected shape hierarchy.
- *In-place editing*: Edit a diagram where it lives, in a source comment, an
  Org or Markdown block, or indented text, without taking over the buffer.
- *Mouse*: Select, drag, resize by corner handles, draw by dragging, with a
  ghost preview and a context menu.
- *Help and tutorial*: A mode-aware key hint, a grouped command palette, a
  generated cheat sheet, an Artist menu, and an interactive tutorial.
- *Diagnose and export*: Explain and repair boxes the parser rejects, and
  export to Mermaid, Graphviz DOT, or SVG.
- *One undo*: Guide changes join ordinary Emacs undo.

* Quick Start

1. Run =M-x shape-artist-scratch= to open a new artist buffer.
2. Press =d= to enter DRAW mode.
3. Use =h= / =j= / =k= / =l= to draw lines.
4. Press =SPC= to set an anchor, then move to draw a rectangle.
5. Press =RET= to commit the shape and return to MOVE mode.
6. Press =C-n= to enter SELECT mode and cycle through detected shapes.
7. Press =?= for the key hints (press it again for the full command palette),
   or run =M-x shape-artist-tutorial= for a guided practice session.
8. To edit a diagram that is already in a file, put point on it and run
   =M-x shape-artist-edit-at-point= (see [[*In-place Editing]]).

** Sidebar and Quick Actions

The sidebar lists parsed shapes with compact metadata IDs such as =sa-1=.
These IDs are best-effort, buffer-local references derived from normalized
geometry and label content.  They do not modify the underlying ASCII diagram and
remain stable across unchanged reparses.  For file-backed buffers, use
=shape-artist-metadata-save=, =shape-artist-metadata-load=, and
=shape-artist-metadata-delete-saved= to persist or clear these IDs in
=.shape-artist/metadata.el= under the current project root.  This identity layer
is intentionally small for now, but it provides the base for semantic operation
history and export round-tripping.

The sidebar shows a compact shape tree, including root, rectangles, and edges.
Tree markers expose interaction state at a glance: =>= marks the current SELECT
candidate, =L= marks the locked SHAPE-EDIT target, and =*= marks a persistent
multi-selection member.  The sidebar also shows parsed diagram bounds, size,
and shape count.  The =?= quick action menu uses Emacs' built-in
=completing-read= interface, so command discovery behaves identically regardless
of optional UI packages.  =o= opens the larger outline tree buffer for
navigation, and =z= centers the view on the parsed diagram bounds.

The active mode is also visible outside the sidebar.  The header line combines a
textual mode/activity badge with a short contextual hint, the mode line repeats
the mode name, and cursor form changes by mode.  These redundant cues avoid
depending on color alone.  All mode faces inherit semantic Emacs faces so light,
dark, high-contrast, and customized themes retain control of their palette.

SELECT highlights the current candidate separately from persistent marked
shapes.  After confirmation, SHAPE-EDIT keeps the locked object or selected
group strongly highlighted until =ESC= ends the edit.

** Object Families and Graph Analysis

Rectangle parsing is family-aware.  The initial grammar recognizes:

- ASCII standard =+---+=, heavy =+===+=, and light =+...+= boxes;
- ASCII rounded boxes using =/= and =\= corners;
- Unicode single-line =┌─┐= / =└─┘= boxes;
- Unicode rounded =╭─╮= / =╰─╯= boxes;
- Unicode double-line =╔═╗= / =╚═╝= boxes.

The entire perimeter must agree with the selected family.  A top border from one
family and bottom border from another is therefore treated as malformed text,
not a rectangle.  Parsed border-family metadata is retained by move/redraw
operations, including Unicode boxes.

Edge objects remain straight segments for stable editing compatibility.  A
second derived graph representation groups segments that share orthogonal bend
points such as =+=.  It records logical connector routes and rectangle adjacency
and exposes connected-component and breadth-first shortest-path queries.  This
separation lets later routing/layout algorithms become smarter without replacing
the existing shape-edit API.


* End-to-End Diagram Manipulation Workflow

The tested manipulation path is intentionally modal and Evil-like, while still
working without Evil installed:

1. In MOVE mode, use =SPC= to anchor and enter DRAW mode, or =d= to enter DRAW
   mode without an anchor.
2. In DRAW mode, use =h/j/k/l= to draw and =RET= to commit.  Shape Artist parses
   the resulting diagram immediately after commit.
3. In MOVE mode, press =C-n= to enter SELECT mode and =n= / =p= to cycle detected
   candidates.
4. Press =RET= in SELECT mode to lock the current rectangle and enter
   SHAPE-EDIT mode.
5. In SHAPE-EDIT mode, use repeatable single-key operations:
   - =H/J/K/L= moves the whole locked shape.
   - =>= / =<= changes width.
   - =+= / =_= changes height.
   - =x= cycles border style among standard, heavy, and light.
   - =h/j/k/l= keeps cursor movement constrained to the shape interior.
6. Press =ESC= to unlock the shape and return to MOVE mode.

The end-to-end regression suite covers this complete flow through the active
keymaps, not only by direct function calls.  It also verifies that heavy and
light borders remain parseable as rectangles after style changes, and that a
locked shape remains locked across repeated move, resize, and style operations.

** Current scope and remaining design choices

The implemented model now covers rectangle-centric ASCII/Unicode box and
straight-edge manipulation: draw, parse, select, multi-select, lock, move,
resize, label, style, arrows, outline, graph analysis, guides, and sidebar
updates all have direct tests, with the modal editing path covered end to end.

Straight connectors also carry endpoint attachment metadata.  Each attached
endpoint records the rectangle geometry, touched side, and side offset.  Shape
movement uses that metadata for the first sticking/rerouting slice:

- moving one rectangle also redraws straight dangling connectors attached to it;
- moving a selected group of rectangles redraws shared straight connectors once;
- if an attached endpoint moves perpendicular to a straight edge, the edge is
  translated on that free axis so it stays parseable as a straight connector.

Remaining larger design areas are explicit future work rather than hidden stubs:

- Junction-aware route vertices and obstacle-aware Manhattan rerouting between
  boxes that move independently.
- Deterministic layered graph layout with crossing minimization and component
  packing.
- Batch alignment/distribution commands beyond grouped move/resize.
- Freeform non-rectangular shapes such as diamonds.

See =docs/feature-roadmap.md= for the algorithm and release roadmap.

* In-place Editing

Diagrams usually live inside other text.  =M-x shape-artist-edit-at-point= finds
the diagram around point, opens it in a separate editing buffer with its comment
prefix or indentation removed, and writes it back when you press =C-c C-c=.
=C-c C-k= discards the session.  Everything outside the diagram lines stays
byte-identical, the write-back is one undo step in the source buffer, and if the
source changed while you were editing you are asked before it is overwritten.

Recognised homes for a diagram:

- runs of comment lines (=;;=, =//=, =#=, =--=, =%=, =*=, =>=, and Org's =:=),
  with or without indentation;
- Markdown code fences and Org example and source blocks, including indented
  ones;
- indented blocks of plain text.

In comments and plain text only diagram-looking lines are taken, so adjacent
prose is left alone.  To edit exactly some lines, select them first: an active
region always wins.  Blank rows and columns the canvas gained while you drew
are trimmed when the diagram is written back.

=M-x shape-artist-insert-diagram= starts a new diagram below the current line,
in the same comment style; nothing is inserted unless you draw something.
These commands have no default key binding, so bind them where you like:

#+begin_src emacs-lisp
(global-set-key (kbd "C-c d") #'shape-artist-edit-at-point)
(global-set-key (kbd "C-c D") #'shape-artist-insert-diagram)
#+end_src

* Mouse

With a pointer (a graphical Emacs, or a terminal with =xterm-mouse-mode=):

| Action                         | Result                                          |
|--------------------------------+-------------------------------------------------|
| Press a shape                  | Select it for editing (SHAPE-EDIT)              |
| Drag a selected shape          | Move it; a ghost outline follows the pointer    |
| Drag a corner handle           | Resize from the opposite corner                 |
| Drag across blank canvas       | Draw a box (a straight drag draws a line)       |
| Click blank canvas             | Deselect and place the cursor                   |
| Shift-press                    | Add or remove a shape from a group selection    |
| Drag a member of a group       | Move the whole group                            |
| Double-press a box             | Edit its label                                  |
| Right-press                    | Context menu for the shape (or the diagram)     |

The buffer changes only when you release the button, and a whole drag is one
undo step.  The sidebar is a navigator too: =RET= or a click on a shape row
selects that shape in the diagram.

* Help and Learning

- =?= shows a one-line, mode-aware key hint; pressing it again opens the
  command palette, grouped and annotated with live keys.
- =M-x shape-artist-help-cheatsheet= shows every key of every mode, generated
  from the keymaps.
- The Artist menu in the menu bar lists the main commands.
- =M-x shape-artist-tutorial= opens a practice canvas with a live checklist:
  draw a box, label it, add a second, connect them, move one, restyle one, and
  undo.  Progress is remembered, and a one-time pointer to the tutorial is shown
  the first time you open =shape-artist-scratch=.

* Diagnosing and Exporting

Press =E= (then a letter) or use the Artist menu:

| Keys  | Command                        | What it does                            |
|-------+--------------------------------+-----------------------------------------|
| =E e= | =shape-artist-explain-at-point= | Says why a box is not detected          |
| =E r= | =shape-artist-repair-at-point= | Fixes the near-miss box at point        |
| =E R= | =shape-artist-repair-all=      | Fixes every near-miss box               |
| =E x= | =shape-artist-export=          | Exports as Mermaid, DOT, or SVG         |

A near-miss is a box the parser rejects on purpose: a mixed border family
(=+---+= over =+===+=), a gap in a border, a missing corner or side character, or
a ragged edge.  Only blanks and another family's border glyphs count as defects,
and repairs are limited to =shape-artist-explain-max-edits= cell changes, so
ordinary text is never reported.

Export labels each box with the text inside it, and draws a connector between
boxes as an edge, with the direction taken from its arrowheads.

* Normalization

=M-x shape-artist-normalize= trims blank rows and columns, adds
configurable padding, and optionally draws a box with a title in
the top border.

The default padding is =(1 1 1 1)= (top, right, bottom, left) and
can be customized via =shape-artist-default-padding=.

* Customization

** User options

- =shape-artist-default-padding=: Default padding for normalization.
  Type: =(list integer integer integer integer)=.
- =shape-artist-default-style=: Border style DRAW uses for new rectangles
  (=standard=, =heavy=, =light=, =rounded=, =unicode-single=,
  =unicode-rounded=, or =unicode-double=).  Lines stay plain ASCII so they
  remain parseable connectors.
- =shape-artist-first-run-hint=: Show the one-time tutorial pointer.
- =shape-artist-tutorial-progress-file=: Where tutorial progress is stored.
- =shape-artist-explain-max-edits=: Largest repair, in cell edits, that
  =shape-artist-explain-at-point= will propose.
- =shape-artist-export-display-function=: How the export buffer is shown.

** Faces

- =shape-artist-preview-face=: Face for shape preview overlays.
  Inherits the current theme's =highlight= face.
- =shape-artist-mode-move-face=, =shape-artist-mode-draw-face=,
  =shape-artist-mode-select-face=, and =shape-artist-mode-edit-face=: semantic
  theme-derived mode badges.
- =shape-artist-select-current-face= and =shape-artist-select-marked-face=:
  current-candidate versus persistent-selection feedback.
- =shape-artist-edit-target-face=: active SHAPE-EDIT object/group feedback.
- =shape-artist-handle-face=: the corner resize handles of the selected box.
- =shape-artist-ghost-face=: the preview outline shown while dragging.
- =shape-artist-explain-face=: the highlight on a near-miss box.

* Evil Integration

When Evil is loaded, Shape Artist defines custom Evil states:

- =artist= (DRAW mode): suppresses normal-state keys
- =select= (SELECT mode): suppresses normal-state keys
- =shape-edit= (SHAPE-EDIT mode): suppresses normal-state keys

MOVE mode uses Evil's =normal= state with overridden keybindings.

Evil state definitions and keymaps are installed when Shape Artist mode is
enabled and Evil is available.  The package also works without Evil installed,
using the built-in modal dispatch keymap.

* Outline Buffer

=M-x shape-artist-diagram-outline-show= opens a tree-view of the
detected shape hierarchy.  Press =RET= on a node to jump to its
position in the artist buffer.

** Shape model

Shapes are represented as EIEIO objects:

- =shape-artist-diagram-node=: Abstract base (x, y, width, height, children).
- =shape-artist-diagram-rectangle=: A rectangle.
- =shape-artist-diagram-edge=: A line with classification (connected,
  disconnected, free).
- =shape-artist-diagram-label=: Text inside a rectangle.
- =shape-artist-diagram-root=: Virtual root of the shape tree.
